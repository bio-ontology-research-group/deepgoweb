DeepGO-PlusPlus-Light v2.0-light is the DeepGOWeb v2 model release for protein and genome-scale annotation. It combines DIAMOND homology transfer, STRING-Net neighborhood evidence, a hierarchy-aware CNN over the Gene Ontology, ESM2-35M embedding kNN and head predictions, and ProteInfer in a learned per-aspect ensemble.

  • Default display threshold: 0.5 for DG++Light.
  • Protein results include per-component prediction streams and can be downloaded as JSON, CSV, or RDF/Turtle.
  • Genome examples use the same release through DeepGO-GSPA; gene calling is limited to prokaryotic genomes unless GFF3/proteins are supplied.
  • Model and evaluation metadata are stored with the archived release directory so retraining creates a new changelog entry by rerunning loadrelease.
